Put your full-size stone photographs in this folder, then run:

    python3 tools/optimize-images.py

Name each file after the key you want to use in assets/js/data.js.
Spaces, capitals and underscores all become hyphens:

    SLATE STONE_COPPER LEATHER.png   ->  slate-stone-copper-leather
    copper-leather.jpg               ->  copper-leather

JPG, PNG and HEIC (straight off an iPhone) all work.
